# EAP — Módulo de Pedidos e Entregas

Estrutura em três níveis, organizada por entregas (substantivos).

```text
1 Módulo de Pedidos e Entregas
  1.1 Requisitos
    1.1.1 Lista de requisitos priorizada
    1.1.2 Histórias de usuário
  1.2 Projeto
    1.2.1 Diagrama de classes
    1.2.2 Protótipo navegável
  1.3 Construção
    1.3.1 API de pedidos
    1.3.2 Telas do aplicativo
  1.4 Entrega
    1.4.1 Plano de testes aprovado
    1.4.2 Pacote de implantação
```

O nível 1 representa o módulo completo; o nível 2 agrupa as entregas; o nível 3 apresenta os pacotes de trabalho. Os itens representam resultados entregáveis, sem verbos de ação.
