# Módulo de Pedidos e Entregas

**Autor:** Vinícius de Andrade Pereira

## Objetivo

Documentar a Estrutura Analítica do Projeto (EAP) de um módulo de pedidos e entregas para um aplicativo de delivery, como atividade de Modelos, Métodos e Técnicas de Engenharia de Software (A1, Turma 2).

A EAP organiza o escopo em três níveis, com foco nas entregas de requisitos, projeto, construção e entrega do módulo.

## Conteúdo

- [EAP.md](EAP.md): estrutura do projeto orientada a entregas.

## Escopo acadêmico

Este repositório apresenta a documentação de planejamento do módulo; não contém uma aplicação implementada.
